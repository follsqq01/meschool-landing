# MESCHOOL — лендинг школы английского

Адаптивный сайт на HTML, CSS и JavaScript без сборки. Сине-красная палитра с белым и светло-серым фоном.

## Запуск

```sh
python3 -m http.server 4173
```

Откройте http://localhost:4173. Для размещения на статическом хостинге используйте корень репозитория.

## Возможности

- Программы для детей, школьников и взрослых.
- Переключение тарифов и длительности занятий.
- Мобильное меню, FAQ и окно записи через администратора.
- Редактор цветов с готовыми и случайными палитрами; выбор сохраняется в браузере.

Основные цвета: синий `#2854D8`, красный `#D93440`, белый `#FFFFFF`, серый `#F3F4F6`. Стили бренда — `brand.css`, палитры — `palette.js`.

Сайт описывает очные занятия в Куркино. Заявки не отправляются в CRM: запись через телефон администратора. Фотография занятия иллюстративная, создана с помощью ИИ.
