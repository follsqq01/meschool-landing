# MESCHOOL — лендинг школы английского

Адаптивный сайт на HTML, CSS и JavaScript без сборки. Сине-красная палитра с белым и светло-серым фоном.

## Запуск

```sh
python3 -m http.server 4173
```

Откройте http://localhost:4173. Для размещения на статическом хостинге используйте корень репозитория.

## Возможности

- Программы для детей, школьников и взрослых.
- Компактная фотосетка из трёх фотографий школы.
- Плавное появление блоков, анимация переключателя тарифов, мягкие градиенты и объёмные карточки.
- Переключение тарифов и длительности занятий.
- Мобильное меню и FAQ, плавное раскрытие информации о преподавателях.
- Магнитные карточки и анимированная прокрутка цифр стоимости.
- Форма с проверкой имени, телефона и двух галочек отправляет заявку в HOLLHOP (meschool.t8s.ru). Отправкой управляет booking.js; подтверждение показывается только после ответа CRM с Id.

Основные цвета: синий `#2854D8`, красный `#D93440`, белый `#FFFFFF`, серый `#F3F4F6`. Стили бренда — `brand.css`, интерактивные элементы — `interactions.css` и `app.js`.

Сайт описывает очные занятия в Куркино. Форма подключена к CRM HOLLHOP. Добавлены отдельные страницы privacy.html и consent.html: документы с реквизитами школы; перед приёмом заявок требуется подтвердить CRM, хостинг и сроки хранения. В первом экране и фотоблоке используются фотографии MESCHOOL.
